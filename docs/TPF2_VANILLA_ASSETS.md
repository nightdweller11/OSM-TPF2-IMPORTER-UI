## Notes

1. **Path Format:** All paths are relative to `res/models/` and should NOT include `model/` prefix when using the API.

2. **Era Suffixes:**
   - `_a` or `era_a` = 1850-1920 (steam era)
   - `_b` or `era_b` = 1920-1980 (diesel era)
   - `_c` or `era_c` = 1980+ (modern era)

3. **Variant Suffixes:**
   - `_new` = Modern version
   - `_old` = Historical version
   - `_mid` = Mid-era version
   - `_1`, `_2`, etc. = Variations

4. **L-Suffixes for Station Assets:**
   - `_l1` = Level 1 (basic)
   - `_l2` = Level 2 (medium)
   - `_l3` = Level 3 (advanced)
